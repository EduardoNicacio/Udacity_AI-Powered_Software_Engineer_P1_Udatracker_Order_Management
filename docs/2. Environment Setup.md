# Environment Setup

For this project, the **Udacity Workspace** is the preferred environment. It provides a preconfigured Docker container with all required dependencies already installed. This ensures you can get straight into practicing Test-Driven Development without worrying about setup issues. However, if you would like to work on your own machine, instructions for setting up a local environment are provided below.

## Udacity Workspace Setup

If you are completing this project in the Udacity Workspace:

1. Python and the required dependencies (`Flask`, `pytest`) are **already installed**, and a VS Code environment is provided.
2. In VS Code, open the terminal (View → Terminal) and navigate to the **project root** (the folder that contains the `backend/` folder):

    ```bash
    cd starter
    ```

3. Start the Flask application:

   ```bash
   python -m backend.app
   ```

4. In the Workspace, open the **Links** menu and click **Flask App**. This will launch the running application in a new browser tab.

## Notes on the Workspace

- If you run into issues with pasting code into the Workspace, try pasting without formatting (command-shift-V or control-shift-V).
- The application must listen on all interfaces (`0.0.0.0`) to be accessible via the "Flask App" link. This is already configured for you in the starter code.
- Flask runs in **debug mode**, so the app will automatically reload when you save changes. It may appear to start twice on first run-this is normal behavior.
- Data is stored **in-memory only**. If you restart the Flask server or the Workspace times out, previously added orders will be lost and you’ll need to restart the server.

## Local Development Setup

If you prefer to run the project locally on your own computer, first ensure that you have installed:

- Python (version 3.13 preferred to match the Workspace environment, though previous versions may work)
- A code editor, such as Visual Studio Code

Then perform the following steps:

1. Clone the starter repository from GitHub and navigate to the project root (starter/ folder):

   - macOS/Linux:

    ```bash
    git clone https://github.com/udacity/cd14599-project-starter
    cd cd14599-project-starter/starter
    ```

   - Windows (PowerShell):

    ```bash
    git clone https://github.com/udacity/cd14599-project-starter
    cd cd14599-project-starter\starter
    ```

2. Create and activate a virtual environment:

   - macOS/Linux:

    ```bash
    python3 -m venv venv
    source venv/bin/activate
    ```

   - Windows (PowerShell):

    ```bash
    python -m venv venv
    .\venv\Scripts\Activate.ps1
    ```

3. Install dependencies from the requirements.txt file located in the backend folder:

   - macOS/Linux:

    ```bash
    pip install -r backend/requirements.txt
    ```

   - Windows (PowerShell):
  
    ```bash
    pip install -r backend\requirements.txt
    ```

4. Run the Flask app from the project root (the folder containing the `backend` folder):

    ```bash
    python -m backend.app
    ```

Open your web browser and go to <http://127.0.0.1:5000>.

## Notes on Local Setup

- Flask runs in **debug mode** with autoreload enabled. Save changes to any file, and the server will restart automatically.
- If port `5000` is already in use on your machine, open `backend/app.py` and change the `port` parameter in `app.run()` (e.g., to `8000` or `8080`).

> Note: The rest of the instructions in this project use Unix-style paths (/). If you are on Windows, adapt commands accordingly (e.g., use backslashes \ in paths).
